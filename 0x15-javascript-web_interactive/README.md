# 7. Fetch Star Wars Character

Fetches a Star Wars character's name from the Star Wars API and displays it inside `div#character`.

## API Endpoint
https://swapi-api.alx-tools.com/api/people/5/?format=json

## Requirements
- Vanilla JavaScript only.
- Use Fetch API with async/await.
- Check response.ok.
- Handle errors with try/catch.
- Display the character name inside div#character.
